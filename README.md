# Yuri Araujo — Personal Website

Minimal, interactive personal website for [yuriaraujo.dev.br](https://yuriaraujo.dev.br), built with **Next.js 16 (App Router + Turbopack)**, **React 19**, **TypeScript**, and **Tailwind CSS v4**.

## Highlights

- **Seamless Full-Page Interactive Canvas** — permanently playable behind the page with zero frames:
  - **Spring-Physics Dragon Curve** — Heighway dragon fractal beside the intro with smooth Gaussian silk-brush touch, full `0°–180°` angle exploration, and 5 lattice presets triggered by orb hits
  - **Drag-and-Throw Orbital Moons** — sling glowing moons across the page; moons near the fractal curve into orbit and release naturally along their tangent line after 3 full revolutions
  - **Pluckable Section Divider Strings & Web Audio** — swipe across any horizontal section divider (or click open space) to strum elastic strings and radiate harmonic ripples
  - **Flow Field** — transparent ambient particle streams that react to your cursor
- **Selected Projects** with live interactive card previews:
  - [Sound Lab](https://sound-lab.yuriaraujo.dev.br/) — harmonic waveform canvas
  - [FreeCell](https://freecell.yuriaraujo.dev.br/) — interactive fanned playing-card tableau
  - [Math Gallery](https://math-gallery.yuriaraujo.dev.br/) — parametric Lissajous curve preview
- **Bilingual (EN / PT)** and **Dark / Light** themes with keyboard shortcuts (`1`–`3`, `T`, `L`).
